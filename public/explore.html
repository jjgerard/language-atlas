Each map answers one question about one place. This page holds all four at once, so you can ask how they relate — whether the places that name a language disorder are the places that teach in a minority language, or where a country's foreign-language entry runs ahead of its newcomer entry. Pick two things and it counts them.

That box is a plain parser, not a chatbot — it matches your words against the variables below and moves the dropdowns. It cannot produce a figure of its own, which is the point: every number on this page is counted from the entries by the same code either way. Nothing here is read out of entry text, for the reason Patterns gives — the wording is hedged, and a classifier run over it leaves the interesting cases unresolved. These variables are what the schema knows about itself: which fields are filled, how many dated rows and sources an entry carries, where it is.

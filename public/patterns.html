What the entries have in common

The maps answer what one place does. This page answers what the places have in common — and, just as often, what none of them record. Everything here is counted from the entries as they stand, so it changes when they do.

Nothing on this page is read out of the entry text. The wording of an entry is deliberately hedged — encouraged but not required, no requirement in primary but 100 hours across Years 7–10 — and a classifier run over it leaves nearly half of the cases unresolved, landing hardest exactly where the answer is interesting. So these counts come only from things the schema already knows: which fields are filled, which dated changes are recorded, which sources an entry cites. A comparative reading of the entries themselves has to be written alongside them, from the same documents, and that layer does not exist yet.

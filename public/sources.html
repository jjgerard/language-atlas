What the atlas rests on

Every document any entry cites, and how far each one reaches. One comparative source can fill hundreds of entry-slots in a single pass; everything else is assembled a country at a time. That difference decides which parts of the map look full first, so it is worth being able to see it directly.

A row counts entry-slots, not documents: a source cited by forty entries counts forty. Where one row stands for many separate pages of the same instrument — a country-profile series, say — it says how many, because that is the difference between a source count and a claim about a single document.

How much of each region leans on a shared source

Of the documented entries in each region, the share citing a source that also documents somewhere else. A high share is not a fault — comparative sources are how any of this gets done — but it does mean those entries move together if the source turns out to be wrong.

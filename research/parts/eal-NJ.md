# Language Atlas — `eal` (Majority language acquisition) — New Jersey

TERMINOLOGY NOTE: the US term is not EAL. New Jersey's regulation has moved further still:
the current N.J.A.C. 6A:15 uses **"multilingual learner" (ML)** as the operative category
and states expressly that it is synonymous with "English learner". The chapter is still
titled *Bilingual Education*. Use "multilingual learner (ML)" and say it is New Jersey's
own term.

ASSESSMENT NOTE: ACCESS for ELLs / WIDA named and linked only. New Jersey's rule refers to
"the Department-established cut score" without printing a number; the 2020 memo does print
one, and it is NOT reproduced here per brief rule 5.

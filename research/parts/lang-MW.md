LANGUAGE NOTE: Citumbuka has no WALS record on that name or on its ISO code tum. NOTE THE TRAP: WALS code 'tum' is Tumleo, an Austronesian language of Papua New Guinea.
LANGUAGE NOTE: Ciyao resolves as WALS 'Yao (in Malawi)' [yao] - one of the rare cases where the WALS code and the ISO code agree. Chinyanja/Chichewa is WALS 'Chichewa' [cic, iso nya]; NOTE THE TRAP: WALS code 'nya' is Nyawaygi, an Australian language.

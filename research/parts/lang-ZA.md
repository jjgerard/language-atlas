LANGUAGE NOTE: Ten of the eleven official languages get a row. English is the eleventh and gets none: it is the language of schooling this map is about the alternatives to, and belongs on the other maps.
LANGUAGE NOTE: isiNdebele (ISO nbl) has no WALS record on name or ISO code; WALS's 'Ndebele' [ndb] carries ISO nde, which is Zimbabwean Northern Ndebele, a different language, so it is NOT substituted here.
LANGUAGE NOTE: SPECTACULAR TRAP: Setswana's ISO code is tsn and Xitsonga's is tso; in WALS's own codes tsn is TSONGA and tso is TSOU, of Taiwan. Both rows here were resolved by WALS name - 'Tswana' [tsw] and 'Tsonga' [tsn] - never by code.
LANGUAGE NOTE: Sepedi resolves as WALS 'Sotho (Northern)' [stn, iso nso]; siSwati as 'Swati' [swt]; Tshivenda as 'Venda' [ven]; isiXhosa as 'Xhosa'; isiZulu as 'Zulu' [zul], WALS also carrying Zulu (Northern) and Zulu (Southern).

DRAFT BULLETS:
 - field: indigenous.mediumOfInstruction
   bullets:
     - No tribal language is a medium: only English and Manipuri, Class I to X
     - Beyond Class X English alone continues as the medium of instruction
     - The thirteen recognised Tribal languages are subjects, never the medium
     - No sanctioned posts exist for regional or minority language teachers
 - field: indigenous.taughtAsSubject
   bullets:
     - Thirteen recognised Tribal languages taught as subjects from Class I
     - Poumai, Liangmei and Gangte run to Class VIII; Mao and Rongmei to Class X
     - Kom, Vaiphei, Mizo, Zou, Tangkhul, Hamar, Thadou-Kuki, Paite run to Class XII
     - A tribal language may be the formula's FIRST language, from Class III to X

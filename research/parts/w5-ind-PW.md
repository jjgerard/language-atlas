NOTES:
 - Title 22 PNCA as consolidated on PacLII prescribes Palauan as a required course; it contains no provision making Palauan the medium for other subjects. §182 requires an applicant for a private school charter only to state "the language in which the instruction is to be given", not to use any particular one.
 - The UNESCO PEER inclusion profile for Palau has no "Ethnic and linguistic groups" section, so it added nothing here.
